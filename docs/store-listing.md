## 概要（132 文字以内 / manifest の description と同じ）

```
X (Twitter) で自分がフォローしているのにフォローバックされていない「片思い」ユーザーに 💔 を表示します。タイムラインのツイートにも対応。
```

## 詳細な説明

```
X (Twitter) で「自分はフォローしているのに、相手からはフォローされていない」ユーザーの名前の横に 💔 を表示します。

■ 表示される場所
・フォロー中 / フォロワー / 検索結果などのユーザー一覧
・タイムラインのツイート（引用元の投稿者も対象）
・プロフィールページ

■ 特徴
・追加のリクエストを一切送りません
・API キーやログイン情報の入力は不要です
・収集・送信するデータはありません。すべてブラウザーの中だけで完結します
・ツールバーのアイコンから、いつでも表示の ON / OFF を切り替えられます

■ 動作条件
Chrome 111 以降が必要です。

■ ソースコード
MIT ライセンスで公開しています。
https://github.com/daruyanagi/Kataomoi
```

## 単一用途（Single purpose）

```
X (x.com / twitter.com) の画面上で、利用者自身がフォローしているにもかかわらずフォローバックされていないアカウントを見分けられるように、その表示名の横に 💔 のアイコンを追加すること。これが唯一の機能です。
```

## 権限の正当化

### `storage`

```
💔 の表示を ON / OFF する設定を 1 項目だけ保存するために使用します。保存するのは真偽値の enabled のみで、閲覧内容やアカウント情報は保存しません。
```

### ホストのアクセス権（`https://x.com/*`, `https://twitter.com/*`）

```
💔 を表示する対象がこの 2 つのサイトの画面だからです。ページ上のフォローボタンの状態と「フォローされています」バッジを読み取って片思いかどうかを判定し、表示名の横にアイコンを挿入します。この 2 サイト以外では一切動作せず、読み取った内容を外部へ送信することもありません。
```

### `world: "MAIN"` のコンテンツスクリプトについて

権限欄ではありませんが、審査で問われた場合はこう説明します。

```
タイムラインのツイートには、ユーザー一覧やプロフィールにあるようなフォロー関係の手がかり（フォローボタン・「フォローされています」バッジ）が画面上に存在しません。

そのため src/interceptor.js が fetch と XMLHttpRequest をラップし、ブラウザーがすでに受け取った X のレスポンスに含まれる relationship_perspectives（following / followed_by）を読み取っています。

・拡張機能から新たなリクエストを送ることはありません。すでに受信済みのレスポンスを読むだけです
・リモートコードの取得・実行は一切行いません。処理はすべてパッケージ内のコードです
・読み取った内容は 💔 の表示にのみ使い、保存も外部送信もしません
・元の呼び出し側には手を加えず、複製したレスポンスだけを読むため、ページの動作には影響しません

ソースコードは MIT ライセンスで公開しています: https://github.com/daruyanagi/Kataomoi
```

## データ利用の申告

収集しているデータはありません。「プライバシーへの取り組み」タブでは以下のように申告します。

| 項目 | 回答 |
| --- | --- |
| 個人を特定できる情報 | 収集しない |
| 健康情報 | 収集しない |
| 財務情報・支払い情報 | 収集しない |
| 認証情報 | 収集しない |
| 個人的なコミュニケーション | 収集しない |
| 位置情報 | 収集しない |
| ウェブ閲覧履歴 | 収集しない |
| ユーザーの操作 | 収集しない |
| ウェブサイトのコンテンツ | 収集しない |

3 つの証明にはすべてチェックを入れられます。

- 承認された用途以外でデータを販売・譲渡していない
- 単一用途と関係のない目的でデータを使用・転送していない
- 信用力の判断や融資目的でデータを使用・転送していない
